How it was made

  • Source: Flask 3.2.0.dev at commit d73fa1c, the 24 files of src/flask.
  • Generator: codeatlas at commit 6836373, run as codeatlas --source flask/src/flask -o site.
  • Diagrams are drawn from Python's AST, with no LLM involved.
  • Sections are written by Claude Sonnet 5.5 (claude-sonnet-5-5), from code chosen by the project's structure (the request path for Data Flow, the exported classes for Key Classes) plus code retrieved from an index of OpenAI text-embedding-3-small embeddings.
  • The run took 41 seconds and cost $0.34 (42,372 input and 25,304 output tokens).

Every section was graded B: accurate, and publishable after small fixes. The problems they found:

  • Integration Points repeats a stale Flask docstring: Flask's Jinja environment does not prefix blueprint names to template names.
  • Overview places two factory methods on the wrong class.
  • Key Classes and Overview often list method names without saying what each method does.
  • Links to headings within a section do not work.
